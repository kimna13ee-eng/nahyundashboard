# FRENGLE 오버뷰 메모

FRENGLE Overview의 오늘 할 일 오른쪽에 별도 메모 체크리스트를 표시한다.
화면이 좁으면 두 카드를 세로로 쌓는다. PERSONAL과 ALL에는 표시하지 않는다.

메모는 입력 후 추가하고 체크박스로 완료·완료 취소한다. 본문을 누르면 바로
수정할 수 있다. 완료한 항목은 접힌 완료 목록에, 삭제한 항목은 휴지통에
표시하며 휴지통에서 복구할 수 있다. 날짜가 바뀌어도 자동으로 지우지 않는다.
메모는 업무·프로젝트·오늘의 업무 통계에 포함하지 않는다.

저장은 회사 DB의 `ops_overview_memos`를 사용한다. 적용 순서는 다음과 같다.

1. FRENGLE 프로젝트에 `supabase/frengle/005_overview_memos.sql`을 적용한다.
   기존 회사 SQL003이 필요하다. PERSONAL에는 적용하지 않는다.
2. 최신 main을 Render에 배포한다. 환경변수 추가는 없다.
3. FRENGLE 로그인 후 Overview에서 등록·체크·수정·휴지통 복구를 확인한다.

`/api/frengle/memos`는 매번 회사 인증과 회원 자격을 확인한다. RLS도 회사
회원이면서 소유자인 행만 허용한다. 일반 사용자는 본문·완료·휴지통 상태만
변경할 수 있고 소유자·ID·저장 시각 수정이나 영구 삭제 권한은 없다.
PERSONAL 연결로 우회하거나 브라우저 저장소에 메모를 보관하지 않는다.

편집을 시작한 시점의 `updated_at` 원문을 유지하여 다른 창의 수정과 충돌을
알린다. 새로고침으로 편집 기준을 자동 갱신하지 않고, 최신 본문을 확인한 뒤
명시적으로 다시 편집할 수 있다. 체크나
저장은 서버가 반환한 결과를 확인한 뒤 반영한다. 메모 카드에서 새로고침할 수
있고, 화면을 보고 있을 때 1분마다 갱신한다. 조회 오류 시 목록을 비우고 다시
시도하도록 안내하며 일반 오류가 나도 작성 중인 입력은 유지한다.

활성 메모는 등록순 최대200개, 휴지통은 최근50개를 조회한다. 조회 범위를
넘으면 제한을 표시한다. SQL은 새 테이블·정책·인덱스·수정 시각 트리거만
추가하며 기존 업무·일정·알림·자동화 데이터는 수정하지 않는다.
