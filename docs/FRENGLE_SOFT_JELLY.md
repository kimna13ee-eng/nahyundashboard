# FRENGLE 소프트 젤리 디자인 — 2026-10-23

PERSONAL에 적용한 소프트 젤리 디자인을 FRENGLE에도 확장한다. 공통 색상과
프레임은 `.editorial.is-jelly-layout`, 회사 화면의 세부 표현은
`.editorial.is-frengle-layout`로 구분한다. ALL 통합 홈은 변경하지 않는다.

크림 배경 `#FFF8F1`, 사이드바 `#FFF1E8`, 브라운 글자 `#3D2C2E`,
20px 카드와 부드러운 그림자, 알약 모양 액션 버튼을 공유한다.
메뉴·섹션에는 컬러 칩과 작은 이모지를 넣고 영문 슬로건을 정리한다.
업무는 코랄, 일정은 민트, 프로젝트는 라벤더, 메모·자동화는 레몬,
설정은 스카이 계열로 표현한다. 완료·오류 상태는 의미를 구별할 수 있게 유지한다.

프로젝트 정보 버튼은 카드 모양을 유지하고, 업무 이름과 메모 본문은
기존처럼 눌러 편집할 수 있다. 오늘 할 일과 메모의 나란한 배치 및 좁은
화면에서의 세로 배치를 유지한다. 메뉴가 많은 회사 사이드바에는 내부
스크롤을 제공하며 고정 타이머와 모바일 메뉴의 위치·본문 여백을 맞춘다.

프로젝트·프로세스, 업무 등록·완료, 빠른 기록, 타이머·중단 업무 재개,
메모 저장·완료·편집·휴지통 복구, 일정·반복 일정, 자동화 결과와 채팅
링크, 일지·라이브러리·분석·계정 기능은 유지한다. PERSONAL과 FRENGLE의
저장소·로그인·데이터 구분을 변경하지 않는다. 데이터 삭제나 이전,
추가 SQL·환경변수 설정은 없다.
