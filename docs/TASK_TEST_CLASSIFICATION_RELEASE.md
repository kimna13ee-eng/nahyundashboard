# 업무 테스트 구분 — 2026-10-14

업무 생성/수정에 일반 업무(false), 테스트 업무(true), 미지정(null)을 추가했다.
명시적인 구분은 기존 isVerificationRecord 판정에서 제목 규칙보다 우선한다.
업무일지와 업무 통계의 테스트 제외 필터에서 이 값을 사용한다.
기존 기록 일괄 변경 없음. 미지정은 기존 제목 판정을 유지한다.

API는 tasks.is_test 열 조회 가능 여부를 전달하고 미설치 환경에서 입력을 숨긴다.
파서는 boolean/null만 허용하며 필드 미전송은 기존 값을 변경하지 않는다.
업무 편집 외 Inbox 변환/콘텐츠/반복 규칙 테스트 분류와 자동 전파는 이번 범위에 없다.
신규 업무 기본값은 미지정이다.

단위 45/45 PASS. 운영 사용자 확인 및 브라우저 저장 동작은 미검증.

업무일지/통계에서 테스트 제외 필터 반영 여부를 확인한다.
