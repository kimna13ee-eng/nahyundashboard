# 회사 PC 사용 절차

현재 다운로드는 준비 중이며 실제 업로드·배포·Storage 설정 승인이 필요합니다.

1. https://my-ops-personal-preview.onrender.com/ 에서 본인 PERSONAL 계정으로 로그인합니다.
2. Settings의 Windows 앱 다운로드가 활성화되면 명시적으로 다운로드합니다. 회사 보안 정책이 개인 서비스 이용/앱 설치를 허용하는지 먼저 확인합니다.
3. PowerShell에서 내려받은 정확한 경로에 `Get-FileHash -Algorithm SHA256 -LiteralPath '다운로드한 파일 경로'`를 실행합니다.
4. SHA256은 d240ca270772f6cd3b91cf0c28d45bd7075bae51570efd1920011159152c12e7과 일치해야 합니다. 불일치하면 실행하지 않습니다.
5. 회사 정책상 허용된 경우에만 설치 파일을 직접 실행합니다. current-user 설치이며 보안/SmartScreen/Defender/조직 정책을 우회하지 않습니다. 설치 파일은 서명되지 않았습니다.
6. 앱을 열고 PERSONAL 계정으로 로그인합니다. 웹과 동일한 서버의 개인 프로젝트·업무·일정을 조회합니다.
7. X는 트레이 숨김, 트레이 클릭은 다시 열기, 메뉴 종료는 앱 종료입니다. 앱 종료가 서버 타이머 종료는 아닙니다.
8. 외부 링크/다운로드가 앱에서 제한되면 트레이 ‘브라우저에서 열기’를 사용합니다.

개인/회사 PC가 같은 PERSONAL 서버 데이터를 사용한다는 의미이며 FRENGLE 운영 DB 연동을 제공한다는 의미가 아닙니다. 회사 기밀·고객 DB·회사 소유 프롬프트를 개인 DB에 반입하지 마세요. 회사 PC 접근/설치와 정책 확인은 사용자가 직접 수행합니다. 회사 PC 실기기 검증은 UNVERIFIED입니다.
