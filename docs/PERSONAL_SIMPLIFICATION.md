# PERSONAL 화면 정리 — 2026-10-23

사용자 확인에 따라 PERSONAL은 콘텐츠 성과·일정·요가 중심으로 정리한다.
FRENGLE 업무 화면과 ALL 통합 홈은 유지한다. DB 마이그레이션이나 원본 자료
삭제, 기존 자동화 연결·푸시 구독 변경은 없다.

PERSONAL 메뉴는 Overview, Calendar, Content Studio, Yoga Planner, Settings다.
Projects, Library, Automations, Work Journal, Analytics는 메뉴에 표시하지
않고 해당 이전 화면 주소는 Overview로 연다. 모바일 메뉴도 같은 범위다.

- Overview: 기존 릴스 성과 TOP 3·나머지 접기와 주간 일정을 유지한다.
  Metricool 자동화 결과·ChatGPT 원문 링크를 유지하며 전체 수신 결과는
  Overview 안에서 펼친다.
- Content Studio: 사용자가 처음 요청한 기획·원고·발행 성과 3시트만 읽는다.
  14개 확장 시트의 선택·조회 허용 목록을 제거한다. Google Sheets 원본의
  시트와 데이터는 변경하지 않는다.
- Calendar: 간단한 콘텐츠명 등록과 요가 일정 연동을 유지한다. 반복 등록과
  선택 기간의 회차 수정·삭제는 유지하고, 규칙 보관·복원/실행 원장/SQL
  안내/일정 휴지통 UI는 개인 화면에서 제거한다. 기존 기록·복구 API와
  자동 정리 정책은 변경하지 않는다.
- Yoga Planner: 주간 뷰, 날짜별 영상 URL·제목·소요 시간, 매일 21시 iPhone
  알림과 알림에서 영상으로 연결되는 경로를 모두 유지한다.
- Settings: 개인 로그인·로그아웃·새로고침과 개인 연차를 유지한다.
  Windows 앱 다운로드, 배포·회사 연결 설명은 개인 화면에서 제거한다.

PERSONAL 전체 화면에서 Quick Log와 비어 있는 TIME TRACKER를 표시하지
않는다. 이미 진행 중인 실제 타이머가 있으면 일시정지·종료할 수 있도록
기존 제어만 남기며 자동 종료하거나 시간 기록을 변경하지 않는다.
상단 데이터 새로고침·오프라인 안내는 유지하고 설치·앱 복구 메뉴만 숨긴다.
