## 기준 및 보존
GitHub main과 기존 Render LIVE 조회 모두 6b330bbaf0b0f4bbf219e4a0cec23bc2bc9785e2. 루트는 Git 저장소가 아니며 기존 work/preview-release-20261011 체크아웃은 깨끗함. safe.directory는 단일 조회 명령에만 지정, 전역 설정 변경 없음. 기존 콘텐츠 helper/단위 테스트 보존. phase2-panel에는 콘텐츠 패치를 유지하고 재전송 보호/재조회 동선을 추가. 다른 기능을 초기화하지 않음.

## 구현
- manifest standalone 및 PNG 180/192/512, Apple 홈 화면 메타데이터, viewport-fit cover.
- 화면을 유지하는 데이터 새로고침, 전체 앱 재시작 별도 확인 패널, 사용/설치 안내, 실행 모드 표시.
- 오프라인 안내, GET 20초 제한, 401 재로그인 안내. 요청 실패 시 기존 저장 성공으로 표시하지 않음.
- 열려 있는 입력창은 앱 재시작 차단. 입력 후 닫기/Escape는 앱 내부 확인 패널; beforeunload 경고. 저장 중 닫기 차단. 민감한 초안 자동 저장 없음.
- 콘텐츠 동시 제출 ref 가드. 전송/응답 파싱 실패 시 재전송 차단 후 목록에서 저장 여부 확인 안내.
- 숨긴 화면의 초당 표시 갱신 정지. 자동 조회는 숨김/오프라인/저장/열린 모달 중 정지; 복귀·online 조회와 2초 중복 이벤트 억제.
- safe-area, dvh 모달, 긴 텍스트 줄바꿈, 모바일 입력 16px·터치44px.

## 한계
강제 종료·OS 메모리 회수 후 미저장 초안은 복구되지 않는다. beforeunload는 모바일 OS 종료를 막지 못한다. 콘텐츠 생성의 서버 멱등성은 아직 없음: 같은 폼 동시 제출/불확실 응답 재전송만 보호. 닫고 신규 등록하면 중복 가능하므로 먼저 목록 확인. 동일 세션 늦은 pause, 실제 두 계정 RLS, 다중 기기/오프라인 경합은 별도 P1.

Windows 구현·EXE는 미착수. 기술·보안 설계 제출 후 승인 필요. 모바일 실기기 및 설치 PWA 검증은 UNVERIFIED. 온라인 설치 경험 보강이며 오프라인 업무 앱 완성을 의미하지 않음.
