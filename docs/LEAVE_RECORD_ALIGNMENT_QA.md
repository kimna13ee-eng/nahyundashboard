# 개인 연차 정렬 QA

연차 전용 CSS와 클래스만 추가했다. 카드 제목/설명/요약/검색창의 기준선·여백을 통일하고 목록 정보와 수정/삭제 액션을 grid로 분리했다. 입력 라벨 간격 6px, 입력/선택 높이 34px, 모바일 카드 padding 16px를 적용했다. 공통 Compact CSS와 기존 이벤트·저장 로직·수량 계산은 변경하지 않았다.

실제 로컬 확인 PASS: PC 1280px 등록 모달/빈 목록, 모바일 375px 등록 모달/빈 목록, 입력 컨트롤 모두 34px, document 가로 넘침 없음, 취소로 닫기. 저장하지 않았으며 연차 원장은 변경하지 않았다.
미검증: 실제 연차 행이 있는 목록, 수정/삭제 확인 모달, 긴 실제 행, 다른 모바일 폭, 모바일 실기기. 목록 정렬은 코드 반영 완료이나 실제 데이터 행 시각 PASS는 주장하지 않는다.

후보: outputs/LEAVE_RECORD_UI_PATCH_MANIFEST.json. 원 Compact 후보는 baseline을 보존하고 이 overlay를 별도 관리한다. Desktop 소스/EXE 변경 없음. 배포하지 않았다.
