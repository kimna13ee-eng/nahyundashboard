## QA 데이터와 한계

`[QA 테스트] 모바일 UX 패치 20261011` 업무와 메모·종료 세션은 보존했다. 진행 중인 QA 타이머는 종료했다. 기존 QA 콘텐츠 제목이 테스트 중 일시 변경되어 원래 `[QA 테스트] 릴스 실사용 일정 20261011`로 복원했으며 변경 이력은 보존했다. 실제 업무 데이터 삭제·초기화는 하지 않았다.

메모 저장과 타이머 시작은 별도 API 요청이므로 원자적이지 않다. 메모 응답을 확인하지 못하면 같은 입력을 무조건 반복 저장하지 않고 상세 확인·새로고침을 안내한다. SQL010/011 서버 가드 계약은 변경하지 않았다.

실제 iOS/Android, 설치 standalone 로그인, 네트워크 단절 후 저장 재시도, OS 뒤로가기/앱 강제 종료, 두 계정 RLS HTTP 테스트는 UNVERIFIED. 브라우저 종료는 beforeunload 범위이며 OS 종료를 앱 확인창으로 보장하지 않는다. 모든 모달의 배경 클릭을 각각 실측하지 않았다. Quick Capture는 단위·격리 DB 회귀를 통과했으나 이번 패치의 신규 브라우저 저장 시나리오는 미검증이다.

인증은 기존 SSR 쿠키/서버 검증을 유지하며 별도 평문 토큰 저장소나 무기한 토큰을 도입하지 않았다. 장기 실기기 세션 유지는 미검증이다. 참고: [Supabase SSR](https://supabase.com/docs/guides/auth/server-side).
