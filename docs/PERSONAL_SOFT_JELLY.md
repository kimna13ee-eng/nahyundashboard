# PERSONAL 소프트 젤리 디자인 — 2026-10-23

PERSONAL의 기존 다섯 메뉴에 사용자 지정 색상과 부드러운 카드·버튼을 적용한다.
스타일은 `.editorial.is-personal-layout` 안으로 한정하며 FRENGLE과 ALL의
화면, 데이터 저장 위치와 업무 동작은 변경하지 않는다.

이후 사용자 요청으로 FRENGLE에도 같은 테마를 확장했다. 공통 스타일은
`workspace-jelly.css`의 `.is-jelly-layout`에서 관리하며 회사 전용 보정은
`frengle-jelly.css`에 둔다. 확장 범위는 `FRENGLE_SOFT_JELLY.md`를 따른다.

| 역할                    | 색상                         |
| ----------------------- | ---------------------------- |
| 배경 / 사이드바         | `#FFF8F1` / `#FFF1E8`        |
| 기본 글자 / 카드 테두리 | `#3D2C2E` / `#F0E0D4`        |
| 릴스·강조               | 코랄 `#FF7A7A`               |
| 주간 일정·캘린더        | 민트 `#6ED9C2`               |
| 요가·배지               | 라벤더 `#C9B6FF`             |
| 알림·하이라이트         | 레몬 `#FFE08A`               |
| 설정 포인트 / 성공 상태 | 스카이 `#9AD7FF` / `#8FD9A8` |

카드는 모서리 20px와 `0 8px 24px rgba(61,44,46,0.08)` 그림자를 사용한다.
액션 버튼은 알약 모양으로 만들고, 메뉴·섹션 아이콘에는 둥근 색상 칩과
작은 이모지를 쓴다. 역할에 따라 선택 메뉴와 강조 버튼의 색도 달라진다.
밝은 강조색 위에는 브라운 글자를 사용해 가독성을 유지한다.

개인 화면의 영문 슬로건과 불필요한 대문자 안내를 정리한다. 로그인과
연결이 정상인 PERSONAL에서는 반복되는 연결 배너를 숨기고 오류·로그인
안내는 유지한다. 기본 글꼴은 기존 Noto Sans KR를 계속 사용한다.

릴스 성과 계산·TOP 3와 접기, 주간 일정, 콘텐츠명 등록, 콘텐츠 3시트,
GPT 결과와 원문 링크, 연차, 요가 주간 계획과 iPhone 오후 9시 알림은
유지한다. 원본 시트, 일정·연차 기록, 알림 구독과 서버 설정을 변경하지
않으며 추가 SQL이나 환경변수 설정은 없다.

검수 시 다음을 확인한다.

- PERSONAL 다섯 화면의 배경·카드·버튼·메뉴 색상과 모바일 메뉴 선택 상태
- 캘린더의 오늘·선택 날짜, 콘텐츠·요가 분류, 모바일 날짜 버튼의 44px 높이
- 일정·요가·연차 모달의 가독성, 키보드 포커스와 저장·취소 동작
- 콘텐츠 표의 내부 가로 스크롤·고정 첫 열과 페이지 전체 폭의 안정성
- 릴스 성과 표시·접기와 기존 링크·일정 등록·알림 제어 유지
- FRENGLE과 ALL 화면에 PERSONAL 스타일이 적용되지 않는지
