# 모바일 실기기 QA 체크리스트

로컬 브라우저 390×844 및 PC 1280×900 검증과 실제 기기 검증은 구분한다. 아래 실기기 항목은 모두 UNVERIFIED.

- [ ] iPhone Safari / Android Chrome에서 로그인 후 홈 화면 추가 및 standalone 실행
- [ ] 전체 앱 재시작 후 기존 로그인 및 PERSONAL 조회 복원
- [ ] 현재 메뉴·워크스페이스 유지하며 헤더 새로고침; 연속 탭 중복 요청 없음
- [ ] 콘텐츠 작성 중 X·취소·Esc/키보드 닫기 확인; 계속 작성 시 입력 보존
- [ ] 네트워크 단절 저장 실패 시 입력 유지; 복귀 후 실제 저장 여부 확인
- [ ] 콘텐츠·긴 프롬프트 입력 중 키보드에 저장/취소가 가리지 않음
- [ ] Calendar 월·주·일·목록에서 원문 상세·연결 업무/콘텐츠 접근
- [ ] QA 업무 시작·중단·재개·종료, 메모/다음 액션 및 새로고침 복원
- [ ] Quick Capture Inbox 저장이 현재 타이머를 멈추지 않음
- [ ] 백그라운드 복귀 시 서버 타이머 재조회; 다중 기기에서 시간 중복 없음
- [ ] 안전 영역·44px 터치·가로 넘침·긴 제목/메모 확인
- [ ] OS 뒤로가기·강제 종료의 입력 손실 한계 확인

검증은 명확한 QA 제목과 비민감 가상 데이터만 사용한다. 실제 업무 삭제·수정 및 회사 연동은 하지 않는다. 현재 후보는 배포되지 않았다.
