# 반복 규칙 보관·복원 — 2026-10-14

반복 일정의 보관 UI를 기존 SQL010 archived_at 필드에 연결했다.
보관은 규칙만 숨기며 회차 예외와 수행 원장은 변경하지 않는다.
복원은 archived_at을 비우며 과거 미확인 회차가 다시 표시될 수 있다.

- Phase2Panel에 전체 규칙 보관·복원 목록 추가.
- API는 PATCH, UUID 및 boolean 검증, same-origin/로그인/owner 필터 유지.
- archived_at 열 조회 가능 여부를 검사해 미설치 환경 버튼 비활성화.
- 공통 occurrences 계산에서 보관된 규칙과 이동된 예외 회차 제외.
- 기존 이력 목록은 보관 여부와 관계없이 유지.
- 새 SQL, 권한 변경, 영구 삭제 없음.
